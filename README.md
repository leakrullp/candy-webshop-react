# Welcome to our world of international candy!

This project is an interactive webshop, where you can browse candies from different categories and countries. Maybe you can even get them at a discount!

## How to run the webshop

You can view the webshop by opening this repository locally and running the commands

```
npm install
npm run dev
```

You can either log in as an existing user using these credentials:

```
username/email: leape@itu.dk
password:       leape123
```

Or you can create your own by navigating to `/register`.
